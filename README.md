# Kids Quest releases

Downloads for the Kids Quest family app (Android). This repo only holds release files:

- `kids-quest-<version>.apk`: the app, signed
- `update.json`: what the app reads once a day to see if there's a newer version

The app's code is kept elsewhere. Nothing about any family is stored here, and the app never sends anything here; it only downloads.

The `test-channel` pre-release is for testing updates and is never offered to the real app.
